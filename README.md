# Authentication Login Dashboard

A simple, beautiful, and responsive login and registration system with a dashboard, built using HTML, CSS, and JavaScript. This project demonstrates client-side authentication using localStorage for data persistence.

## Features

- **User Registration**: Create new accounts with email and password
- **User Login**: Secure login with email and password validation
- **Dashboard**: Protected dashboard page accessible only after login
- **Remember Me**: Option to remember login credentials
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Modern UI**: Beautiful gradient backgrounds, smooth animations, and professional styling
- **Client-side Storage**: Uses localStorage for user data and session management

## Technologies Used

- **HTML5**: Structure and semantic markup
- **CSS3**: Modern styling with gradients, transitions, and responsive design
- **JavaScript (ES6+)**: Client-side logic, form validation, and localStorage management

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ajaysai157/authentication-login-dashboard.git
   ```

2. Navigate to the project directory:
   ```bash
   cd authentication-login-dashboard/Project
   ```

3. Open `index.html` in your web browser to start using the application.

## Usage

### Registration
1. Open `register.html` in your browser
2. Fill in your email and password
3. Confirm your password
4. Click "Register" to create your account

### Login
1. Open `index.html` in your browser
2. Enter your registered email and password
3. Check "Remember me" if you want to stay logged in
4. Click "Login" to access the dashboard

### Dashboard
- After successful login, you'll be redirected to the dashboard
- View your welcome message
- Click "Logout" to end your session

## Security Notes

⚠️ **This is a demonstration project only!**

- User data is stored in browser localStorage (not secure for production)
- Passwords are stored in plain text (never do this in real applications)
- No server-side validation or encryption
- For production use, implement proper backend authentication with secure password hashing
